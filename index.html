So läuft das

  1. 1
    Einzeiler kopieren. Da oben. Ein Klick. Mehrmals machst du das eh.
  2. 2
    Ausführen. In PowerShell einfügen, Enter. Das Script macht den Rest: Java-Check, Fabric-Profil, Mods. Du chillst.
  3. 3
    Zocken los. Im offiziellen Launcher das Profil fabric-loader-0.19.5-1.20.1 picken. Die Vanilla-Dateien zieht er beim ersten Start selber.

Warum das safe ist

  • Nochmal laufen lassen? Idempotent – es checkt kurz, überspringt korrekte Dateien und fertig. Nix bricht.
  • Deine alten Mods landen in <Zeitstempel>modbackup, nicht im Nirvana. Zurückholen easy.
  • Kein Java auf dem PC? Das Script holt sich Temurin JRE 17. Kein Stress.
  • Jeder Download wird auf Größe und SHA1 geprüft. Keine kaputte Datei kommt durch.

Kein offizielles Mojang-/Microsoft-/Fabric-Produkt. Minecraft gehört denen, die Mods ihren Machern. Installiert wird nur Fabric für 1.20.1 – nichts anderes. GG.
