Minecraft 1.20.1 + Fabric

Sieben fest gepinnte Mods von Modrinth – installiert mit dem offiziellen Fabric Installer. Nur Fabric, nur 1.20.1, nichts anderes.

Einzeiler-Installation (Windows PowerShell)
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/DeutscherCOder/fabric-1.20.1-modpack/main/install.ps1 | iex"

Das Script erkennt %APPDATA%\.minecraft von selbst, legt das Fabric-Profil an, lädt die Mods herunter und prüft jeden Download per SHA1. Fremde Mod-Jars werden vorher in einen <Zeitstempel>modbackup-Ordner verschoben.

Alle Versionen sind fest gepinnt und wurden gegen die Modrinth API verifiziert. Separate Quell-/API-Jars werden ignoriert – installiert wird ausschließlich die primäre .jar-Datei je Mod.

So installierst du

  1. 1 Öffne PowerShell, füge den Einzeiler oben ein und bestätige mit Enter.
  2. 2 Das Script lädt – falls nötig – Java, installiert den Fabric-Loader (aktuellste Version für 1.20.1) und danach alle Mods.
  3. 3 Starte den offiziellen Launcher und wähle das Profil fabric-loader-…-1.20.1.

Geprüfte Details

  • Wiederholte Ausführung ist gefahrlos – korrekte Dateien werden übersprungen (idempotent).
  • Nicht benötigte Mod-Jars landen als Sicherung in <Zeitstempel>modbackup.
  • Jeder Download wird auf Größe und SHA1-Prüfsumme geprüft.
  • Sollte Java fehlen, lädt das Script automatisch Temurin JRE 17.
