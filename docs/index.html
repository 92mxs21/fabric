Minecraft 1.20.1 Fabric Modrinth Windows · PowerShell

Minecraft 1.20.1 + Fabric Modpack

Ein Einzeiler installiert Minecraft 1.20.1 mit Fabric (neuester Loader) und genau sieben versionierten Mods – vollautomatisch und idempotent.

Der One-Line-Befehl — in PowerShell oder auch in cmd einfügen:

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/DeutscherCOder/fabric-1.20.1-modpack/main/install.ps1 | iex"

Schon in einem PowerShell-Fenster? Dann reicht: irm https://raw.githubusercontent.com/DeutscherCOder/fabric-1.20.1-modpack/main/install.ps1 | iex

✓ Befehl kopiert!

🔧 Was wird installiert?

  • Minecraft 1.20.1 (Fabric) – Profil über den offiziellen Fabric Installer (CLI), der Loader wird immer automatisch auf die neueste verfügbare Version für 1.20.1 gesetzt.
  • Exakt 7 Mods von Modrinth in fest gepinnten Versionen – nur Fabric/1.20.1-Dateien, verifiziert per SHA1-Prüfsumme.
  • Backup: Bereits vorhandene, nicht benötigte .jar-Mods werden vor der Installation in einen datierten mods-backup-Ordner verschoben.
  • Idempotent: Ein erneuter Lauf installiert nichts doppelt und ist gefahrlos.

⚡ Voraussetzungen

  • Windows mit PowerShell 5.1 oder neuer (ist standardmäßig installiert).
  • Der offizielle Minecraft-Launcher (einmal gestartet, damit der .minecraft-Ordner existiert).
  • Java 17 für Minecraft 1.20.1 (falls nicht gefunden, lädt das Script automatisch Temurin JRE 17).
  • Internetzugriff zu meta.fabricmc.net, maven.fabricmc.net und api.modrinth.com.

🔁 Wie funktioniert das Script?

  1. Lädt die Konfiguration config/modpack.json (aus dem Repo, wenn nötig).
  2. Erkennt automatisch %APPDATA%\.minecraft.
  3. Prüft Java und lädt bei Bedarf Temurin JRE 17 herunter.
  4. Ermittelt neuesten Fabric Loader für 1.20.1 und lädt den offiziellen Fabric Installer.
  5. Installiert das Fabric-Profil per java -jar fabric-installer.jar client -mcversion 1.20.1 -loader <neueste> -dir <.minecraft>.
  6. Sichert fremde .jar-Mods in mods-backup\<Zeitstempel>.
  7. Lädt die 7 gepinnten Mods von der Modrinth API und verifiziert jede SHA1-Prüfsumme.

🔗 Nützliche Befehle

Nur prüfen / Vorschau (DryRun):

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/DeutscherCOder/fabric-1.20.1-modpack/main/install.ps1 -OutFile $env:TEMP\install.ps1; & $env:TEMP\install.ps1 -DryRun"

Lokal aus dem Repo ausführen:

git clone https://github.com/DeutscherCOder/fabric-1.20.1-modpack.git && cd fabric-1.20.1-modpack && .\install.ps1

Mit eigenem Minecraft-Ordner:

.\install.ps1 -MinecraftDir D:\Spiele\.minecraft
